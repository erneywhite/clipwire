# Сайт Clipwire

Статический сайт на Astro с анимациями на GSAP и плавной прокруткой на Lenis.
Английская версия лежит в корне, русская в `/ru/`. Тексты обеих версий собраны
в `src/i18n/strings.ts`.

## Сборка

```sh
cd site
npm ci
cp .env.example .env    # и вписать адрес сайта в SITE_URL
npm run build           # результат в site/dist
```

Адрес из `SITE_URL` нужен для canonical, hreflang, `sitemap.xml` и картинки
для соцсетей. Без него сайт тоже собирается, только ссылки будут относительными
и `sitemap.xml` не появится.

`npm run dev` запускает сайт локально с перезагрузкой при правках.

## Выкладка

На выходе обычная статика, на сервере достаточно nginx. Содержимое `site/dist`
(не саму папку) кладут в корень сайта. Файлы в `_astro/` содержат хеш в имени,
их можно кешировать надолго:

```nginx
location ^~ /_astro/ {
    expires 1y;
    add_header Cache-Control "public, max-age=31536000, immutable";
}
```

Ссылки на скачивание при сборке берут версию из `Cargo.toml`, а в браузере
сверяются с последним выпуском на GitHub. Поэтому после нового выпуска
программы сайт пересобирать не обязательно.

## Что ещё отдаёт сайт

- `robots.txt` (поисковики и ИИ-боты разрешены явно) и `sitemap.xml`;
- `llms.txt`: выжимка о проекте для ИИ-ассистентов, собирается из тех же текстов;
- JSON-LD с описанием программы и вопросами-ответами на каждой странице.
