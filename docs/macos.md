# Клиент для macOS

План этапа 4 и задание для работы на маке. Проект целиком собирается на macOS уже сейчас:
вся платформенная часть сидит за `cfg(windows)`, а на остальных ОС стоят заглушки. Задача
этапа — заменить заглушки настоящей работой с macOS, не сломав Windows.

## Состояние на старте (проверено на M1 Pro, macOS 27.2)

- `cargo build --workspace --all-targets`, `npm run build` и clippy с `-D warnings` проходят.
- `cargo test --workspace`: 312 прошли. Падает то один, то другой сетевой тест сервера с
  «Too many open files (os error 24)»: у macOS лимит 256 открытых файлов на процесс, а
  параллельные тесты поднимают десятки iroh-эндпоинтов. По одному всё проходит. Перед
  тестами — `ulimit -n 10240`, то же в CI для macOS. **Сделано:** записано в README и в п. 7.
- `rekey_moves_group_to_new_key` (сервер, `tests/devices.rs`) под нагрузкой иногда
  получает «слишком много соединений» вместо «исключено» при повторном входе R: место
  прошлого соединения освобождается позже, чем приходит отказ. Хелпер `joined()` эту гонку
  уже обходит повтором, а входы через `join_plain` в конце теста — нет. **Сделано:** все
  повторные входы идут через хелпер `joined_plain()` с тем же повтором.

## Решения

- Сборка universal (arm64 + x86_64), проверка на Apple Silicon. Минимальная версия —
  macOS 13 (Ventura).
- Без нотаризации: подписи Apple Developer нет. Приложение подписывается ad-hoc
  (`codesign -s -`), README объясняет первый запуск (снять карантин или «Всё равно
  открыть»). Автообновление дальше работает само: Tauri качает обновление внутри
  программы, карантина у него нет.
- Иконки в Dock нет, только значок в строке меню (`LSUIElement`, activation policy
  Accessory), как у остальных утилит буфера.
- Горячая клавиша по умолчанию Cmd+Shift+V (`CommandOrControl+Shift+V` уже так и
  работает).
- Ветка `macos`. В `main` попадает после проверки на Windows-ПК и зелёного CI на всех
  трёх ОС.

## Что сделать

Порядок важен: слежение за буфером — основа, без него остальное не проверить.

### 1. Буфер обмена (`crates/clipwire-agent/src/clipboard.rs`)

Сейчас на macOS `Watcher::start` возвращает ошибку «ещё не реализовано», запись умеет
только текст через `arboard`.

- Модуль `mac` рядом с `win`, через `objc2` / `objc2-app-kit` (`NSPasteboard`). Уведомления
  о смене буфера в macOS нет: опрос `changeCount` раз в 250 мс в отдельном потоке.
- Чтение: текст (`public.utf8-plain-text`), HTML (`public.html`) и RTF (`public.rtf`) в
  `Content::Rich`, картинки (`public.png`, иначе `public.tiff` с переводом в PNG), файлы и
  папки (`NSURL` через `readObjectsForClasses`) в `Content::Files` через `local_file_ref`
  (сейчас она только для Windows).
- Приватное содержимое не трогать: типы `org.nspasteboard.ConcealedType`,
  `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType` (ими помечают
  1Password, Bitwarden, KeePassXC и другие). Это то же, что `ExcludeClipboardContentFromMonitorProcessing` на Windows.
- Запись всех видов `Content`, включая файлы (`writeObjects` с `NSURL`) и Rich (несколько
  типов в одном элементе). Своё же копирование не считать новым: защита от петель
  (`loopguard.rs`) сравнивает содержимое, `changeCount` после записи запоминать.
- `WatchOptions` и колбэк — те же, что у Windows. Второй аргумент колбэка — exe/bundle
  программы-источника, см. п. 2.

Критерий: `cargo run -p clipwire-agent -- run` на маке ловит копирование текста,
форматированного текста из Safari, скриншота (Cmd+Shift+Ctrl+4) и файлов из Finder, а
вставка из истории кладёт их обратно так, что вставляется в TextEdit, Finder и браузер.

### 2. Программа-источник (`source_app.rs`)

Буфер macOS не знает, кто в него писал. Берём активную программу в момент смены
(`NSWorkspace.frontmostApplication`): имя (`localizedName`), bundle id для списка
исключений и иконку 32×32 в PNG. Исключения в настройках на маке — по bundle id или имени
(`com.agilebits.onepassword7`, `KeePassXC`).

### 3. Вставка в активное окно (`apps/desktop/src-tauri/src/popup.rs`)

- Перед показом окна запомнить активную программу (`NSRunningApplication`), после выбора
  вернуть её (`activateWithOptions`) и послать Cmd+V через `CGEvent`.
- Для синтеза нажатий нужно разрешение «Универсальный доступ» (Accessibility). Проверка
  `AXIsProcessTrustedWithOptions` при первой вставке; если разрешения нет — объяснение в
  окне и кнопка, открывающая нужный раздел настроек. Без разрешения работает «только в
  буфер».
- Окно вставки у курсора и в пределах рабочей области монитора уже кроссплатформенное,
  проверить на нескольких мониторах и со строкой меню.

### 4. Оболочка Tauri

- Меню приложения с пунктами «Правка» (Cmd+C/V/X/A/Z): без него в полях WebView на маке
  не работают копирование и вставка.
- `LSUIElement` и activation policy Accessory, чтобы не было иконки в Dock.
- Значок в строке меню — шаблонная (template) иконка, чёрно-белая, macOS сама красит её
  под тему. Сейчас в `tray.rs` цветной провод и проверка темы панели Windows: на маке
  состояние показывать текстом в меню, а значок — шаблоном (сделать вариант для «нет
  связи», например перечёркнутый).
- Заголовок окон: свой `TitleBar.svelte` нарисован в стиле Windows (кнопки справа). На
  маке — «светофор» слева или системный заголовок (`titleBarStyle: Overlay`).
- Скрытие окон при демонстрации экрана: `NSWindow.sharingType = none`.
- Окно предпросмотра размера без активации (`settings_window.rs`) — проверить, как ведёт
  себя на маке, при необходимости `orderFront` без `makeKey`.

### 5. Секреты (`secret.rs`)

Сейчас на macOS ключ группы и доступы к хранилищу лежат открыто в файле с правами 0600.
Перенести в связку ключей (`security-framework`, generic password, служба
`io.github.erneywhite.clipwire`). Старый файл при первом запуске перенести и удалить.

### 6. Мелочи

- Имя устройства по умолчанию (`settings.rs`): `SCDynamicStoreCopyComputerName` или
  `scutil --get ComputerName`. Сейчас на маке выйдет «Это устройство».
- Звук копирования (`sound.rs`): тот же синтезированный щелчок через `NSSound` из памяти.
- Отметка «скачано из интернета» (`blobs.rs`, `mark_from_internet`): атрибут
  `com.apple.quarantine` на скачанных с других устройств файлах.
- Язык системы для «как в системе» (`i18n.rs`): `NSLocale.preferredLanguages`, а не
  переменные окружения (у программ из Finder их нет).
- Путь данных уже правильный: `~/Library/Application Support/Clipwire` (через `directories`).

### 7. Сборка и выпуск

- CI (`.github/workflows/ci.yml`): `macos-latest` в матрицу — fmt, clippy, тесты. Тесты на
  macOS — через `ulimit -n 10240 && cargo test --workspace` (шаг с `shell: bash`): без этого
  сетевые тесты упираются в предел 256 открытых файлов.
- Выпуск (`release.yml`): задание для macOS, `tauri-action` с `--target universal-apple-darwin`,
  ad-hoc подпись, `.dmg` и файлы обновления (`Clipwire.app.tar.gz` + `.sig`). `latest.json`
  должен содержать и `windows-x86_64`, и `darwin-aarch64` / `darwin-x86_64`: задания
  выпуска собирают его вместе (`tauri-action` дописывает платформы в общий файл выпуска).
- README и README.ru.md: установка на macOS, первый запуск без нотаризации, разрешение
  «Универсальный доступ».

## Как работать на маке

- Репозиторий: `~/Documents/ClaudeCode/Clipwire`, ветка `macos`. Rust 1.100 (rustup, с
  целью `x86_64-apple-darwin`), Node 26, Command Line Tools уже стоят.
- Правила проекта — в `CLAUDE.md`: тексты для человека через `tr()` / `t()` с английским
  переводом (тесты полноты `i18n`), новая логика — с тестом, срезанные углы помечать
  `shortcut:`, сообщения коммитов по-русски, без строк Co-Authored-By.
- Не ломать Windows: всё платформенное — за `cfg(target_os = "macos")`, общий код не
  менять без нужды. После каждого шага: `cargo fmt --all`, `cargo clippy --workspace
  --all-targets -- -D warnings`, `cargo test --workspace`, `node src/lib/*.test.ts` из
  `apps/desktop`.
- Запуск приложения из исходников: `cd apps/desktop && npx tauri dev`. Настоящая сборка:
  `npx tauri build --target universal-apple-darwin`.
- Чтобы не трогать рабочие данные, для проверок — отдельная папка: `CLIPWIRE_HOME=/tmp/cw-test`.
- Всё, что требует человека у экрана (нажать горячую клавишу, выдать разрешение, вставить
  в окно, посмотреть на значок), собирать в список «ручные проверки» с точными шагами и
  ожидаемым результатом и отдавать человеку пачкой, а не по одной.
