# Скриншоты

Снимки для README и превью репозитория. Сняты с чистого экземпляра Clipwire,
чтобы в кадр не попали своя история, адрес сервера и обои:

- Clipwire запускается с пустой папкой данных: `CLIPWIRE_HOME=<пустая папка>`, в ней
  `settings.json` с `{"language":"en","theme":"graphite","mode":"dark"}`. Основной
  экземпляр на это время закрыт: иначе второй не запустится, а демо-записи уйдут в
  настоящую историю и группу.
- Демо-записи копируются из обычных программ (Блокнот, Paint, Проводник), чтобы у них
  была настоящая программа-источник. Файлы лежат в нейтральной папке, путь виден в
  карточке файла.
- Окна снимаются ровно по границам (`DwmGetWindowAttribute`, `DWMWA_EXTENDED_FRAME_BOUNDS`),
  скруглённые углы прозрачные.

Превью репозитория (`docs/brand/social-preview.png`, 1280×640) собирается из
`paste-window.png`: `node scripts/social-preview.mjs` из `apps/desktop`. Загружается
вручную: Settings → General → Social preview.
